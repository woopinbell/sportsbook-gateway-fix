# 게이트웨이 검증·측정 상태

## 현재 코드 판정

현재 코드로 `GatewayLoadTest`와 전체 스택 k6 시나리오를 재측정한 결과가 없습니다.
따라서 WebSocket 동시 연결 수, 전달 지연, REST 처리량, p99 또는 오류율 수치를
현재 성능으로 제시하지 않습니다.

현재 테스트는 인증 경계, 라우팅 계약, 호출 제한의 Redis 장애 시 허용, Kafka 이벤트의
사용자별 STOMP 전달 같은 기능을 검증합니다. 이 기능 검증을 처리량 인증으로
해석하지 않습니다.

## 참고용 측정 자료

[`2026-05-30/summary.md`](2026-05-30/summary.md)는 게이트웨이, 내장 Kafka,
WireMock을 한 JVM에서 측정한 개발 환경 자료입니다. 현재 코드의 대표 결과나 여러
호스트 운영 환경의 용량 증거가 아닙니다.

성능 수치를 공개하려면 게이트웨이와 공통 계약의 버전, 브로커 구성, 분리된 하위
서비스, 연결 수, 장비·네트워크 조건을 함께 기록해 재측정해야 합니다.
